# UAS1
 
PDF y word sobre sistemas de aeronaves no tripuladas (UAS/drones).
 
## Contenido
 
1. **Tipos de UAS** — clasificación por configuración aerodinámica (multirrotor, ala fija, ala rotatoria, VTOL híbrido), por tamaño/peso (nano, mini, táctico, MALE, HALE) y por uso (recreativo, comercial, gubernamental, militar).
2. **Cuadro comparativo por gama, calidad y costo** — 4 niveles de gama con ejemplos, rango de precios (COP), calidad de sensores, autonomía y público objetivo.
3. **Partes de un dron** — 13 componentes principales (chasis, motores, ESC, hélices, controladora de vuelo, batería, GPS, IMU, cámara/gimbal, radiocontrol, sistema FPV, sensores de obstáculos, antenas) con su función.
4. **Tipos de operación de vuelo** — VLOS, EVLOS y BVLOS según alcance visual del piloto.
5. **Tipos de metraje** — fotografía aérea, video, timelapse/hyperlapse, panorámica 360°, ortomosaico/mapeo, modelado 3D, termografía y vigilancia.
